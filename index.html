MBL · 데이터 모델링

MBL 데이터 기반 끓는점 모델링 수업

여러 물질의 끓는점을 MBL 온도 센서로 측정하고, 학생이 직접 데이터 전처리와 시각화를 수행한 뒤, 생성형 AI 바이브 코딩으로 끓는점을 수학적으로 정의하는 모형을 제작한 수업입니다. 측정 데이터를 정량적 모형으로 연결하는 탐구 경험을 설계하였으며, AIEDAP 인공지능융합수업 연수에서 배운 내용을 토대로 기획하였습니다.

간이 염분 측정기 만들기 및 센서 보정

학생이 부력과 밀도를 이용해 간이 염분 측정기를 직접 제작하고, 표준 용액으로 측정한 뒤 전기전도도·염도 센서를 기준기로 삼아 보정하여 미지 시료의 염분을 측정하는 탐구 수업입니다. 직접 제작한 과학 시뮬레이션과 '높이 → 염분 변환기' 실습 도구를 함께 활용해, 측정·보정·데이터 분석을 통합적으로 경험하도록 설계하였습니다.

직접 개발한 바이브 코딩 과학 수업 도구

단일 HTML 및 풀스택(Supabase) 기반으로 직접 제작하여 수업에 활용한 도구들입니다.

풀스택 · Supabase

질문하는 교실

학생이 자신의 질문을 직접 기록·제출하고, 쌓인 질문으로 수업을 열고 닫는 Supabase 기반 풀스택 웹앱입니다. 학급 로그인(인증)과 데이터베이스를 직접 구축해 학생용 공간과 교사용 현황을 나누었고, 질문이 쌓일수록 성장하는 게이미피케이션으로 학생의 질문 활동을 장려합니다. 프론트엔드부터 백엔드까지 교사가 직접 설계한 풀스택 개발 사례입니다.

03

교외 활동 · 과학 부스 운영

교외 과학 축제에서 운영한 과학 부스를 디지털 탐구 콘텐츠로 재구성한 사례입니다.

교외 부스 · 2025 서울융합과학·수학·메이커 축제

CSI 과학수사대 — 로마의 사라진 보석

'CSI 수사대: 과학으로 추리하라' 방탈출 부스를, 학생이 직접 추리하며 과학 원리를 익히는 단일 HTML 웹앱으로 재구성한 프로젝트입니다. 학생은 수사관 아바타를 만들고, 대기압·편광·화학발광(루미놀)·광변색이라는 네 가지 과학 수사 기법을 단계별로 수행해 단서를 모으며 진범을 추리합니다. 실험 결과가 다음 단계의 단서로 이어지는 연역적 추리 구조로 설계하였고, 오프라인 부스의 일회성 제약을 넘어 반복 학습이 가능한 디지털 콘텐츠로 확장하였습니다.
